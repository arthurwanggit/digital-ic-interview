# Digital IC Interview (数字芯片设计模拟面试)

OpenCode 技能 — 面向 0-3 年经验的数字芯片设计工程师进行模拟面试。所有提问绑定候选人实际项目经历进行深挖。

## 使用方法

1. 确保已安装 [OpenCode](https://opencode.ai)
2. 将本目录复制到 OpenCode 的 skills 目录下（或通过环境变量配置 skill 路径）
3. 在 OpenCode 中调用此 skill 即可开始模拟面试

## 功能特性

- **简历驱动** — 支持粘贴文本、文件路径，自动解析项目经历
- **17 大知识点覆盖** — 总线协议、低速外设、SOC 系统、存储、时序分析、RTL 编码、验证调试、设计流程、算法安全IP、低功耗、先进工艺/DFT、后端物理设计、时钟树综合(CTS)、信号完整性/天线效应、物理布线、IR Drop/电源完整性、标准单元/工艺库
- **分层追问** — 每个知识点配备 L1 基础 → L2 深入 → L3 边界三层追问
- **结构化反馈** — 面试结束后按 4 个维度评分并提供改进建议
- **题目复盘** — 面试后可逐题回顾，提供参考答案，支持追问
