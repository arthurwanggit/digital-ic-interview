# Digital IC Interview (数字芯片设计模拟面试)

OpenCode 技能 — 面向 0-3 年经验的数字芯片设计工程师进行模拟面试。所有提问绑定候选人实际项目经历进行深挖。

## 面试流程

| 阶段 | 内容 |
|---|---|
| 1. 获取简历 | 支持粘贴文本或文件路径，自动解析 |
| 1.5 候选人画像 | 提取院校层次、工作年限、跳槽频率 |
| 2. 项目深挖 | 6道项目题 + 2道基础概念题 |
| 3-4. 编码实战与开放设计 | 待补充 |
| 5. 总结反馈 | 4维度评分 + 预期薪资估算 |
| 复盘 | 逐题回顾，提供参考答案 |

## 功能特性

- **简历驱动** — 支持粘贴文本、文件路径，自动解析项目经历
- **候选人画像** — 内置 52 所院校权重表，提取学历/年限/跳槽频率，用于后续薪资估算
- **17 大知识点覆盖** — 总线协议、低速外设、SOC 系统、存储、时序分析、RTL 编码、验证调试、设计流程、算法安全IP、低功耗、先进工艺/DFT、后端物理设计、CTS、信号完整性/天线效应、物理布线、IR Drop/电源完整性、标准单元/工艺库
- **分层追问** — 每个知识点配备 L1 基础 → L2 深入 → L3 边界三层追问
- **预期薪资估算** — 综合院校权重、工作年限、目标公司分档、城市系数、面试表现、跳槽稳定性，输出月薪与年包估值
- **结构化反馈** — 按 4 个维度评分并提供改进建议
- **题目复盘** — 面试后可逐题回顾，提供参考答案，支持追问

## 预期薪资估算

面试结束后，综合候选人院校背景、工作年限、目标公司档次、所在城市、面试表现及跳槽稳定性，以面试官口吻给出预期月薪与年包估值。计算过程及参数不对外展示。
